# Assets Play Store (hors app)

Captures d'écran et visuels marketing pour les fiches Google Play Console des deux apps
mobiles — **ne fait pas partie du code embarqué** (à ne pas confondre avec
`mobile_app/assets/` / `mobilipro/assets/`, qui eux sont packagés dans l'APK).

- `mobile_app/screenshots/` — captures voyageur (recherche trajet, réservation, billet QR,
  covoiturage, etc.)
- `mobilipro/screenshots/` — captures pro (dashboard partenaire/gare, scan QR, admin, etc.)

Format Play Store : PNG/JPEG, ratio 16:9 ou 9:16, 320px–3840px sur le plus grand côté.

Les fichiers image réels sont ignorés par Git (voir `.gitignore`) — seule cette structure de
dossiers est versionnée. Garde une copie de sauvegarde locale ou dans un espace partagé.
